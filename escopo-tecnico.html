Checklist de tarefas

A ordem em que vou tocar o projeto.

Criar projeto no Supabase

Rodar o script SQL que cria as tabelas loja e produtos, as regras de segurança e o armazenamento de imagens.

~15 min
Criar a conta de acesso da loja

Cadastrar o e-mail e senha da minha amiga no Supabase e registrar os dados da loja (nome + WhatsApp).

~5 min
Configurar as chaves no código

Colar a URL e a chave pública do Supabase no arquivo config.js.

~5 min
Subir no GitHub e ativar o Pages

Criar o repositório, enviar os arquivos e ligar a hospedagem. Site no ar com link próprio.

~15 min
Montar o bot no Typebot

Criar o fluxo de conversa, conectar a IA (Gemini) e configurar o redirecionamento para o WhatsApp ao finalizar.

~40 min
Incorporar o bot no site

~5 min
Cadastrar os produtos reais

contínuo
Testar a ponta a ponta

Cadastrar produto → ver na vitrine → clicar em comprar → cair no WhatsApp → tirar dúvida no bot.

~20 min

O balãozinho de dúvidas + IA

Sim — é o Typebot, e ele aceita conectar uma LLM.

O que o bot faz

  • Aparece como bolha no canto do site
  • Responde dúvidas sobre os produtos com IA
  • Funciona 24h, sem eu/ela precisar responder
  • Ao finalizar, leva o cliente pro WhatsApp

Como conecto a IA

  • Typebot tem bloco nativo de OpenAI (pago)
  • Ou bloco de requisição HTTP → API do Gemini (grátis)
  • Vou usar o Gemini pra não ter custo
  • A chave sai do Google AI Studio
Resposta direta: o campo do balãozinho é conectado ao Typebot, sim. E o Typebot aceita integrar uma LLM (OpenAI nativo, ou Gemini/qualquer outra via requisição HTTP). O cliente conversa com a IA e, na hora de comprar, é redirecionado pro WhatsApp.
# Chamada que o Typebot faz ao Gemini (bloco HTTP)
POST https://generativelanguage.googleapis.com/v1beta/
       models/gemini-2.5-flash:generateContent?key=SUA_CHAVE

# corpo da requisição
{
  "system_instruction": { "parts": [{ "text":
     "Você é a atendente da loja. Tire dúvidas e, na hora
      de comprar, envie o cliente pro botão do WhatsApp." }] },
  "contents": [{ "parts": [{ "text": "{{pergunta}}" }] }]
}
